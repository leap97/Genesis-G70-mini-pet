G70 Mini Pet — 공개용 기술 설명

구조
- Windows Forms, GDI+와 Win32의 투명 레이어 창을 사용하는 단독 실행 프로그램.
- 소스는 Desktop.cs, 이미지 자산은 assets, 검증 코드는 tests에 분리되어 있다.
- 배포 EXE에 10개의 PNG 자산을 포함한다. 실행할 때 외부 이미지나 브라우저가 필요하지 않다.
- 일반 실행 파일에는 테스트 명령과 테스트용 화면 저장 기능을 포함하지 않는다.
- Windows .NET Framework 컴파일러로 빌드하며 추가 패키지나 네트워크 연결을 요구하지 않는다.

입력 처리와 저장 범위
- WH_KEYBOARD_LL 훅으로 키 종류를 판별한 뒤 해당 입력의 시각만 Motion.Stroke에 전달한다.
- 문자 변환, 입력 문장 보관, 클립보드 읽기, 다른 앱의 이름 수집을 하지 않는다.
- 타수 계산에는 최근 입력 시각을 최대 9개 사용한다. 입력 시각과 계산 기록은 파일에 저장하지 않는다.
- 한글 IME 입력과 키 자동 반복을 키 눌림 기준으로 집계한다. Ctrl/Alt/Windows 단축키와 붙여넣기는 가속 입력에서 제외한다.
- 네트워크 통신, 자동 시작 등록, 레지스트리 설정, 별도 서비스를 사용하지 않는다.
- 종료 시 키보드 훅, 타이머, 알림 영역 아이콘, 그래픽 자원을 해제한다.

로컬 설정
- source/boost.txt: 부스트 구간, 효과 강도·속도, 경고 기본 확률.
- source/window.txt: 창 위치·크기. 형식은 x,y,size,3이다.
- 두 파일은 공개 배포와 Git 추적에서 제외한다. 파일이 없거나 읽을 수 없으면 기본값으로 시작한다.
- boost.txt는 설정창에서 저장할 때 생성한다. 임시 파일과 원자적 교체를 사용해 저장 실패 시 기존 값을 유지한다.
- window.txt는 이동·크기 변경·종료 시 저장한다. 이전 위치 형식도 읽을 수 있다.
- 설정창의 취소는 값을 적용하지 않는다. 기본값 복원은 저장해야 반영된다.

기본값과 부스트 모델
- 시작/중간/유지/고속 타수: 150 / 400 / 500 / 600타/분.
- 중간/유지/고속 압력: 1.49 / 1.50 / 1.70 bar. 공회전 압력은 -0.62 bar.
- 시작 타수 미만에서는 음압~0 bar, 시작~중간 구간은 0~중간 압력으로 선형 보간한다.
- 중간~유지 구간은 중간~유지 압력으로 선형 보간한다. 유지~고속 구간은 유지 압력을 목표로 한다.
- 고속 타수 초과에서는 고속 압력을 목표로 하며, 실제 압력은 시간에 따라 목표값으로 부드럽게 변한다.
- 타이핑이 느려지면 완만하게 감압하고, 입력이 끊기면 빠르게 공회전 음압으로 돌아온다.
- 타수 설정은 1~1199의 오름차순, 압력 설정은 0~2.00 bar의 오름차순이며 같은 압력을 허용한다.
- LED는 소수 둘째 자리까지 반올림한 표시값이 1.50 bar 이상일 때 켜진다.

문구와 경고
- 양압에서 입력이 갑자기 끊기면 Stututututu를 1초간 표시한다. 재입력하면 즉시 숨긴다.
- 경고 기본 확률은 0%, 설정 범위는 0~100%이다.
- 압력이 1.5 bar 이하에서 엄격히 초과로 진입할 때마다 추가 확률을 2.5%포인트 누적한다.
- 초과 상태를 유지하는 동안은 중복 집계하지 않는다. 기본 확률과 추가 확률의 합은 최대 100%이다.
- 적격 감속 이벤트마다 한 번 추첨해 문구 또는 경고등·P0234·경고 표정을 표시한다.
- 경고가 표시되면 다음 타이핑까지 유지한다. 그때 경고와 추가 확률을 함께 초기화한다.
- 경고가 없는 감속·재입력·일시정지에서는 누적된 추가 확률을 유지한다.
- 경고 표정의 동공은 300ms 간격으로 움직이며, 재입력하면 멈춘다.
- 경고 코드와 압력은 화면 연출용 값이다. 실제 차량 진단이나 센서 데이터가 아니다.

렌더링과 자산
- 기준 좌표계는 1200×1200이다. 기본 그림 배율은 320px, 메뉴 선택은 180/240/320/400/480/600px이다.
- Layer.Viewport가 바깥 투명 여백을 자른다. 기본 실제 창 크기는 309×244px이며 내부 배율은 바꾸지 않는다.
- 효과와 경고 표시를 포함한 고정 표시 범위를 유지한다. 프레임마다 창 크기를 바꾸지 않는다.
- car/dial/hub/led/flutter는 차체·게이지·바늘 축·LED·문구 자산이다.
- front/rear/far에는 각각 128개 회전 프레임이 들어 있다. faces/warning-faces는 표정 자산이다.
- 휠·타이어·디스크 무늬는 같은 회전각을 사용한다. 캘리퍼는 고정된 위치에서 스포크에 가려진다.
- 바퀴 프레임과 차체의 기준 좌표, 접지점, 캠버 변환을 함께 유지한다. 정지 스포크를 차체에 중복해서 넣지 않는다.
- front 프레임 크기는 154×239, 배치 좌표는 (233,779)이다.
- rear 프레임 크기는 132×209, 배치 좌표는 (53,751)이다.
- far 프레임 크기는 160×56, 배치 좌표는 (710,952)이다.
- IdleLift는 차체와 눈에만 적용하고 타이어 형상과 게이지 위치에는 적용하지 않는다.
- 차체·눈의 공통 세로 오프셋은 Renderer.BodyLowering에서 관리한다. PNG와 코드 좌표를 따로 변경하지 않는다.
- 국소 그림 수정에서는 보호할 윤곽, PNG 크기·알파·해상도 메타데이터를 유지한다. 반복 리샘플링으로 선명도가 떨어지지 않게 한다.
- 이미지 변경 후 확대 화면과 실제 표시 크기를 모두 확인한다.

효과와 대기 동작
- 들썩임 강도와 모션블러 강도는 기본 100%, 범위 0~200%이다.
- 들썩임 속도와 눈 깜박임 속도는 기본 100%, 범위 25~200%이다.
- 기본 대기 들썩임 주기는 3.8초이며 속도 배율에 반비례한다. 위상을 누적해 설정 변경 시 위치가 튀지 않게 한다.
- 대기 눈 깜박임과 시선 동작은 타이핑·감속·문구·경고 상태보다 우선하지 않는다.
- 주행 잔상은 뒤쪽 차체와 지붕 윤곽 밖에만 합성한다. 얼굴·엔진룸·휠·타이어·게이지·문구는 선명하게 유지한다.
- 0 bar 이하, 정지 또는 블러 강도 0%에서는 잔상을 그리지 않는다. 바람선 자체에는 블러를 적용하지 않는다.
- 대기 애니메이션은 약 30fps, 주행 갱신 타이머는 16ms이다. 정지 상태에서는 불필요한 갱신을 줄인다.

빌드
- 일반 빌드: .\source\build-desktop.ps1
- 다른 출력 경로: .\source\build-desktop.ps1 -OutputPath .\source\qa\G70.exe
- 검증 빌드: .\source\build-desktop.ps1 -Test
- 검증 파일은 source/qa/G70.Tests.exe에 생성된다. 같은 경로의 실행 파일을 교체하려면 해당 파일만 종료한다.
- 공개 패키지 준비 시 개인 설정, 작업 폴더, 원본 사진, 브라우저 프로필, 검증 결과를 포함하지 않는다.

검증
각 명령은 결과를 저장할 폴더 인수가 필요하다.
예: .\source\qa\G70.Tests.exe --self-test .\source\qa\self-test

- --self-test: 기준 수치 데이터와 모델 비교, 키 분류, 압력·LED·감속·재입력, 기본 렌더링.
- --animation-test: 대기·눈 동작 속도, 들썩임, 입력 우선순위, 부스트별 잔상과 선명도.
- --warning-test: 확률 경계, 경고 유지, 동공 움직임, 재입력 해제, 일반 문구 표시 시간.
- --overboost-test: 1.5 bar 초과 진입 집계, 2.5%포인트 누적, 초기화와 확률 상한.
- --settings-test: 값 검증, 저장·불러오기, 기본값, 이전 설정 형식, 설정창 동작.
- --bounds-test: 여러 크기와 상태에서 차체·바퀴·효과·경고의 잘림, 화면 모서리와 위치 복원.
- --smoke-test: 실제 투명 창, 크기 변경, 포커스 유지, 키보드 훅 설치·해제.

tests/reference.csv는 수치 모델 회귀검사 기준 데이터이며 입력 문자나 개인 설정을 포함하지 않는다.
검증 EXE는 자체 경로 아래의 설정을 사용하므로 다른 폴더에서 실행 중인 미니펫의 설정과 분리된다.
생성되는 source/qa 폴더는 Git 추적과 공개 ZIP에서 제외한다.
